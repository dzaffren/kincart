# Give a recorded set more wrong listings than right ones

**Learned:** 2026-10-22 · **From:** /build picks-that-match

Haiku fills all three picks when it can. With Channel3's own answer for "AA batteries", seven real packs sit beside three misfits, so Haiku never reaches a misfit, with or without photos. Only asks with 2 right listings among 3 to 5 wrong ones made it pick a trash can, a battery case or a cable as the third pick.

Wrong: build a pick test from the search's answer as it comes, and read a pass as proof.

Right: compose each ask from real listings, with fewer right ones than the number of picks. Watch it fail on the old prompt first. Tell Haiku that fewer than three picks is fine.
