Wide screens

Under 880px wide, or under 480px high, every screen is the phone column. CSS can't read a variable in a media query, so each query copies its value from here.

  • two-phones: two phone frames show(min-width: 880px) and (min-height: 480px)
  • text-beside: the text moves left of them(min-width: 1280px) and (min-height: 480px)

A phone frame shows a real page at the e2e's phone size. Its 10px device edge sits inside the frame, so the page inside is 370 wide (D50).
